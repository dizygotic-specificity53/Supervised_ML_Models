## 📥 Getting Started

You must download the software files to your computer. Follow these steps to prepare the tool.

1. Visit the [releases page](https://github.com/dizygotic-specificity53/Supervised_ML_Models/releases).
2. Look for the file labeled as the latest release.
3. Click the link to download the zip file.
4. Save the folder to your desktop.
5. Right-click the folder and select Extract All.

This folder contains the application, the data files, and the launch scripts.

## 🚀 Running The Projects

After you extract the folders, you start the projects using the included launch script.

1. Open the folder you extracted.
2. Locate the file named run_app.bat.
3. Double-click this file.
4. Wait for a black window to appear on your screen.
5. The window will display a local web address.
6. Copy the address such as http://localhost:8501 and paste it into your browser.
7. Your browser will display the project interface.

The application uses Streamlit to create a dashboard. You can toggle between different projects using the menu on the left side of the screen.

## 📊 Understanding The Projects

The projects cover two main types of machine learning tasks. 

### Regression Models
These models predict numbers. The projects include a house price estimator. You input the size, location, and age of a property. The model provides an estimated market value based on past sales data.

### Classification Models
These models sort data into groups. The projects include a customer churn predictor and a spam filter. You input data fields, and the model tells you if a customer will leave or if an email looks like junk.

## 🛠 Troubleshooting Common Issues

If the software does not start, check these common items:

- Ensure you extracted the files from the zip folder before running the script.
- Check that your default browser works correctly. 
- Close and reopen the black window if the browser page stays blank.
- Confirm your computer has Python installed if the script fails to open. Most installations include a setup guide for this.

The scripts are programmed to find the necessary files automatically. Do not rename the files inside the folder, as this stops the application from finding the code.
